# ADR-001: 采用 Monorepo + apps/ 布局

| 项目 | 内容 |
|---|---|
| 状态 | Accepted |
| 决策日期 | 2026-09-25 |

## 背景
FireSight 需要核心引擎(数据/训练/评估/推理)与火灾烟雾应用(场景包/监测业务)两端，
并可能扩展 Web 端。

## 备选方案
- 方案 A: 平铺布局
- 方案 B: Monorepo + apps/ (采纳)
- 方案 C: Multi-repo

## 决定
方案 B: Monorepo + apps/，仿照参考项目 ODPlatform。

## 理由
1. 多端共享代码零摩擦
2. 跨端原子变更
3. 与实训/参考项目设计范式对齐

## 后果
- 正面: 多端启动零摩擦、跨端测试自然就位
- 负面: 首次安装路径稍长
- 中性: 需要 marker file + 双层 pyproject

## 撤销条件
仓库规模/团队规模显著变化时重新评估。
