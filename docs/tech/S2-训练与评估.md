# S2 技术设计 —— 训练与评估

## 目标

配置驱动训练，实验可追溯，指标可对比。

## 推荐默认（已确认）

| 参数 | 值 |
|---|---|
| model | yolo11n.pt 主训练 |
| 对照 | yolo11s.pt（fs-val 多权重对比） |
| epochs | 50（冒烟 3） |
| imgsz / batch / lr0 | 640 / 8 / 0.01 |
| patience / seed / device | 10 / 42 / 0 (CUDA) |
| 日志 | Ultralytics CSV + 项目 logging |

## 流程

fs-gen-config → train.yaml 模板
fs-train → DEFAULT < YAML < CLI → YOLO.train → 归档
fs-val → 单权重评估 / 多权重对照

## 归档

- runs/training/<run_id>/ 过程现场
- models/trained/<run_id>/ best.pt + train_config.yaml + metrics.txt


## 提速（A+B+E 已落地）

- batch 8→16，workers 默认 8，patience 早停
- `--fraction` 子集实验、`--cache` 内存缓存
- 转换时剔除 w/h 非正退化框（D-Fire 14 处）
