# S1 技术设计 —— 数据工程

## 目标

原始火灾数据集「进得来、转得动、分得稳、查得清」，产出可训练 YOLO 成品。

## 流程

```
data/raw/<dataset>/
    |  images/ + annotations/(xml|json|txt)
    v
fs-transform
    - convert   VOC/COCO/YOLO -> YOLO txt（归一化 + clip）
    - report    类别平衡统计
    - split     固定种子 random 8:1:1（可复现）
    - material  复制到 processed/<dataset>/{images,labels}/{train,val,test}
    - yaml      data.yaml + transform_stats.json
    v
fs-validate（只读）
    - snapshot  一次扫描共享
    - checks    5 项自动发现质检
    - report    quality_report.html / .json
```

## 关键决策

| 决策 | 说明 |
|---|---|
| 合并流水线 | `fs-transform` 同时做转换+划分，避免半成品 |
| 冻结划分 | 固定 seed（默认 42），同种子 100% 可复现；训练只读 processed |
| 注册表 | 转换器/划分策略/check 自动发现，扩展不改主干 |
| snapshot | 质检一次扫描，多 check 共享 |
| HTML 报告 | Jinja2 模板 + Matplotlib 类别柱状图 |

## 目录约定

- `data/raw/<name>/images` + `annotations|labels`
- `data/processed/<name>/images|labels/{train,val,test}` + `data.yaml` + `reports/`

## 类别

默认双类：`flame` / `smoke`（`FireSmokeClass`）。
