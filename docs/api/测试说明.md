## 如何查看结果

### 终端（最快）

```powershell
.venv\Scripts\Activate.ps1

# 全部
pytest tests apps/platform/tests -v

# 只跑某一序号
pytest apps/platform/tests/test_03_convert_split.py -v
pytest tests/test_10_infer_integration.py -v
```

- 行尾 `PASSED` / `FAILED` / `SKIPPED`
- 汇总行形如：`27 passed in 6.03s`

### 保存到文件（便于留档）

```powershell
pytest tests apps/platform/tests -v --tb=short > test_report.txt 2>&1
```

### 算覆盖率（可选，需 `pytest-cov`）

```powershell
pytest tests apps/platform/tests --cov=fire_sight_platform --cov=frame_source --cov=visualization --cov=fire_sight --cov-report=term
```
